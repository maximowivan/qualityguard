# QualityGuard - IT Quality Assurance Company Website

Веб-сайт для компании, предоставляющей IT-услуги в сфере контроля качества IT-проектов.

## 🎯 Функциональные возможности

### Основные страницы:
1. **Главная** - визитная карточка компании, преимущества, статистика
2. **О нас** - информация о компании, команда, сертификаты
3. **Услуги** - подробное описание услуг, таблица сравнения
4. **Контакты** - контактная информация, форма обратной связи, FAQ
5. **Админ-панель** - управление пользователями и заявками

### Система пользователей:
- Регистрация и авторизация (всплывающие окна)
- Личный кабинет с историей заявок
- Разделение на пользователей и администраторов

### Работа с заявками:
- Форма связи с компанией
- История заявок в профиле пользователя
- Административное управление заявками
- Фильтрация и поиск заявок

## 🛠 Технологический стек

### Frontend:
- **HTML5** - семантическая разметка
- **Tailwind CSS** - стилизация (utility-first framework)
- **JavaScript (ES6+)** - интерактивность
- **Font Awesome** - иконки

### База данных:
- **LocalStorage** - эмуляция SQLite для хранения данных
- Структура данных:
  - Пользователи (users)
  - Заявки (applications)

### Архитектура:
- **Модульная структура** - разделение на компоненты
- **SPA-like навигация** - плавные переходы между страницами
- **Всплывающие модальные окна** - для авторизации и профиля
